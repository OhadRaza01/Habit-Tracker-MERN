# Habitly

Habitly is a full-stack habit tracker designed to help users build better habits, track their daily progress, and stay consistent over time.

I built Habitly primarily for my own use because I wanted a simple and personal way to track my habits, monitor my consistency, and see my progress over time. The idea was also inspired by the principles discussed in *Atomic Habits*, especially the importance of building small habits and staying consistent.

## Features

- User registration and authentication
- Create, update, and delete habits
- Daily habit tracking
- Individual habit streaks
- Overall current streak
- Habit completion statistics
- Daily progress overview
- Responsive user interface

## Tech Stack

### Frontend

- React
- Tailwind CSS
- Axios

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
